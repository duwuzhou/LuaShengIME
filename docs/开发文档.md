# 开发文档

## 概览
LuaShengIME 是基于 `.NET 8 for Android`（`net8.0-android`）开发的中文输入法项目，核心输入引擎为 Rime，并集成用户词库、快捷短语、候选预测、资源加密与 Release 混淆能力。当前主工程位于 `IME/IME/`，文档默认以仓库根目录 `E:\Development Project\IME` 为执行起点。

## 项目结构
```text
IME/
├─ docs/                          # 项目文档
├─ IME/                           # 主 Android 输入法工程
│  ├─ Assets/                     # Rime 资源、加密布局输出目录 enc/
│  ├─ Features/                   # 输入、候选、设置、短语、词库等业务模块
│  ├─ Resources/                  # Android 资源
│  ├─ Shared/                     # 输入引擎、公共工具、资源保护
│  ├─ Theme/                      # 主题
│  ├─ libs/arm64-v8a/             # librime.so / libc++_shared.so
│  ├─ tools/                      # 加密、混淆脚本
│  ├─ IME.csproj                  # 主项目
│  └─ IME.sln                     # 主解决方案
└─ website/                       # 宣传站点
```

## 环境准备
- `.NET 8 SDK`，并安装 Android workload
- Android SDK / Build Tools
- JDK
- Windows PowerShell
- `adb`（用于安装与调试）

## 常用命令
- Debug 构建：`dotnet build IME\IME.sln -c Debug`
- 清理：`dotnet clean IME\IME\IME.csproj`
- Release 发布：`dotnet publish IME\IME.sln -c Release`
- 兼容模式发布（关闭裁剪/AOT，适合排查兼容问题）：
  `dotnet publish IME\IME.sln -c Release /p:PublishTrimmed=false /p:TrimMode=false /p:RunAOTCompilation=false`
- 启用混淆发布：
  `dotnet publish IME\IME.sln -c Release /p:RunObfuscator=true /p:ObfuscarExe="C:\path\Obfuscar.Console.exe"`
- 安装 APK：
  `adb install -r E:\Development Project\IME\IME\IME\bin\Release\net8.0-android\publish\com.companyname.IME-Signed.apk`

## 构建配置
- 目标框架：`net8.0-android`
- 最低系统版本：`SupportedOSPlatformVersion=21`
- 输出类型：`Exe`（Android APK/AAB 应用）
- 默认 ABI：`android-arm64`
- 基础配置中关闭裁剪：`PublishTrimmed=false`、`TrimMode=false`
- `Release` 配置默认开启：`PublishTrimmed=true`、`TrimMode=partial`
- `RunObfuscator` 默认关闭，需要在发布时显式传入 `true`

## Release 资源加密与混淆
Release 构建会执行两类保护流程：

### 1. XML 资源加密
- 密钥来自 `IME/IME/IME.csproj` 中的 `EncryptedResourceKeyBase64`
- `tools/GenerateEncryptedResourceConfig.ps1` 在编译前生成运行时配置
- `tools/EncryptResources.ps1` 在 Release 构建前加密布局 XML 到 `Assets/enc/`
- `Resources/layout/*.xml` 默认在 Release 下从 `AndroidResource` 中移除，仅白名单布局保留明文
- 运行时解密入口：`Shared/ResourceProtection/EncryptedLayout.cs`

### 2. C# 代码混淆
- 混淆脚本：`IME/IME/tools/obfuscate.ps1`
- 混淆工具：Obfuscar
- 发布时通过 `/p:RunObfuscator=true` 启用
- Debug 保持明文，便于排查问题

## 输入引擎生命周期
- 输入法服务入口：`Features/Input/Ime.cs`
- 异步初始化管理：`Features/Input/InputEngineManager.cs`
- Rime 引擎实现：`Shared/InputEngine/RimeInputEngine.cs`

当前实现已处理两个关键稳定性问题：
- 首次切入输入法时，Rime 通过异步方式初始化，避免阻塞 UI。
- 从其他输入法切回本输入法时，不再每次都强制执行 `StartMaintenance + Deploy`。现在会依据资源版本、分页配置、部署状态文件和 `user/build` 产物决定是否重新部署，从而修复“切回后偶发不可用或长时间无响应”的问题。

另外，针对部分设备上 `process_key` 偶发返回 `false` 的情况，已经增加 `SimulateKeySequence` 兼容兜底。

## Rime 资源与词库
- Rime 方案资源位于 `IME/IME/Assets/rime`
- 用户数据目录运行时位于应用私有目录 `files/rime/user`
- 词库、方案补丁更新后，必要时可在应用内触发重新部署
- 候选分页设置会写入 `default.custom.yaml`，变更后会触发重新部署

## 调试建议
- 构建前确认 `IME/IME/libs/arm64-v8a/` 下原生库完整
- 若怀疑切换输入法后异常，优先查看 `adb logcat` 中 `IME`、`RimeInputEngine`、`RimeNativeBindings` 日志
- 若 Release 出现兼容问题，先使用“兼容模式发布”排除裁剪/AOT影响

## 提交约定
- 仅提交 `IME/IME/**` 范围内需要变更的内容
- 不提交 `IME/IME/Assets/enc/` 这类生成产物
- 文本文件统一使用 UTF-8 编码
